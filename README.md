# 理財計畫 Webapp

Google Sheet（資料）＋ Apps Script（Code.gs）＋ GitHub（網頁）＋ Vercel（託管與 /api/data 代理）。

## Vercel 環境變數
APPS_URL（Apps Script /exec）、API_TOKEN（同 Apps Script 指令碼屬性）、APP_PASSWORD（網頁登入密碼）。

## 設定
日常調整請直接在 App 右上角的齒輪進入「設定」，不必再開試算表；App 內的修改會寫回下面這幾張表，直接在試算表改也一樣有效。

## 設定表（依「你要做什麼」分成五張）
| 工作表 | 用途 | 平常要動嗎 |
|---|---|---|
| 設定 | 一般設定：項目／值／說明（房貸月扣覆寫、提醒天數、異常門檻、代墊帳戶、手續費預設折扣、每月固定支出、通知診斷） | 偶爾 |
| 設定-帳戶 | 每個帳戶一列：信用卡每月扣款日、繳款帳戶、銀行／扣帳通知來源、信用卡消費通知來源 | 新增銀行時 |
| 設定-通知規則 | 系統看不懂的通知寫法（網頁編輯記帳時按「記住這種寫法」會自動新增） | 幾乎不用手動 |
| 設定-股票 | 每檔持股的券商與手續費折扣 | 新增券商時 |
| 設定-貸款與目標 | ① 貸款　② 利率變更　③ 長期里程碑 | 偶爾 |

舊版「設定」的資料第一次載入時會自動搬進新表，並留下「設定(舊版備份)」工作表。

## 其他工作表
- 交易紀錄：買進／賣出／股利流水帳（網頁「記一筆」寫入，可撤銷最新一筆）
- 歷史：每次儲存的快照　紀錄：錯誤與自動扣款紀錄
- 股票部位 H 欄：持股券商（自動維護）

## 自動化（執行一次 setupTriggers）
每月 1 日提醒與月報、每月 2 日備份、每天 06:00 信用卡自動扣款。

## 部署
Apps Script 貼上 Code.gs → 新版本部署；GitHub 推送 index.html、src.css 等 → Vercel 自動建置。
